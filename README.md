# PhotoUnlocked Support Site

Static privacy and support pages for the PhotoUnlocked App Store listing.

## Publish with GitHub Pages

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.
4. GitHub Pages publishes the site at `https://ioskevinshah.github.io/photounlocked-site/`.

The expected App Store URLs are:

- `https://ioskevinshah.github.io/photounlocked-site/privacy/`
- `https://ioskevinshah.github.io/photounlocked-site/support/`

The privacy policy must be reviewed against the final release build and all included SDKs before App Store submission.
